# 08: The juggler

**What to build:** The juggler game: a mouse-controlled catching game runs beside a message box while the Player replies to a message, typed in one round and by voice in the other, so they feel why hands-free matters. It saves caught and dropped counts, words, and an approximate three-item rubric (place, time, who).

**Blocked by:** 03

**Status:** done

- [x] Catching and replying work at the same time
- [x] Typed and voice rounds use different messages, with randomised first mode and a type-it-instead option
- [x] Caught, dropped and words are saved
- [x] The rubric hit count comes from simple keyword matching and is labelled approximate
