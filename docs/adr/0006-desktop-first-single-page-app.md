# Desktop-first single-page app

Flow's Usage stats exist only on Mac and Windows, and the headline outcome depends on a streak card, so the headline group plays on laptops. The app is a static single-page app designed at 1280 to 1440px wide, with the HUD on top and Blip docked bottom-left. Phones load the same app with stacked layouts and a bottom-sheet bubble, but their results are reported separately.

Consequence: India's desktop-to-mobile usage is about even, so the portfolio states that a desktop-only group does not represent mobile users.
