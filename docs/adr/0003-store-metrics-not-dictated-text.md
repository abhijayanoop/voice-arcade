# Store metrics, not dictated text

Players speak about real irritations and ideas. Only Describe to decode descriptions are stored as text, because Judges must read them; every other round stores counts, durations, ratings and rates. This keeps the data safe to publish in aggregate and removes the need to scrub private content. The cost is that we cannot re-score rounds later, so scoring rules are fixed before Sunday's sessions.

Consequence: the consent text must disclose that descriptions are shown to outside Judges, anonymously.
