# Players are identified by a personal link, not an account

Friends return on days 2 and 3 and must not hit a sign-up wall. Registering returns a long random token, stored in the browser and embedded in the personal link; every write presents it. There are no passwords, emails or accounts. Trade-off: anyone holding a link can act as that player, which is acceptable for ten to fifteen friends and a research page with no sensitive data.

Consequence: tables deny all direct access, and the token is checked inside each RPC function.
